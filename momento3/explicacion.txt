Para desarrollar este programa, primero identifiqué las partes principales de un ascensor: botones, puertas, pisos y el movimiento del ascensor.
Cada parte la representé con una clase distinta en Java para organizar el código de manera clara y siguiendo principios de programación orientada a objetos.
Ascensor: mantiene el piso actual y se mueve hacia arriba o abajo según la solicitud del usuario.
Puerta: controla la apertura y cierre automático al llegar a un piso, evitando obstáculos.
Boton: registra cuando el usuario solicita un piso y activa indicadores visuales.
Piso: representa cada nivel del edificio
SistemaControl: coordina todas las clases y presenta un menú interactivo para que el usuario pueda llamar al ascensor o seleccionar destinos.
El programa funciona de forma interactiva en consola, mostrando mensajes que simulan el movimiento del ascensor y la apertura de puertas.
El diseño modular facilita la comprensión del código y permite futuras mejoras, como agregar múltiples ascensores o alertas de fallas.
En resumen, el código simula de manera sencilla y organizada el funcionamiento de un ascensor, aplicando principios de POO y asegurando que cada clase cumpla un rol específico dentro del sistema.
